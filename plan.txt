# Frontend Webapp Integration Guide

## Project Overview

Build a standalone React webapp that integrates with an elizaOS backend for the **"test-dd-local"** agent. This is a custom client (not using `@elizaos/client`) deployed on Vercel with separate dev/prod environments.

## Backend Deployment

### Production Backend URL

**Live Backend**: https://3a6615a6-aeris-agent.containers.elizacloud.ai/

### Backend Deployment Instructions

The backend is deployed using elizaOS Cloud. For deployment details, see:

- **Deployment Guide**: See `MANUAL_DEPLOYMENT.md` in the project root
- **elizaOS Cloud**: https://www.elizacloud.ai
- **Deployment Script**: `deploy-manual.ps1`

#### Quick Deployment Steps

1. **Get API Key**:ershell
   elizaos login
   # Or set manually:

API Integration

API Endpoints
Send Message: POST /api/agent/{agentId}/messages
Body: { text: string, conversationId?: string }
Response: { messageId: string, conversationId: string }
Get Messages: GET /api/agent/{agentId}/messages?conversationId={id}
Response: { messages: Message[] }
Get Conversations: GET /api/agent/{agentId}/conversations
Response: { conversations: Conversation[] }
Get Agent Info: GET /api/agent/{agentId}
Response: { agent: AgentInfo }
WebSocket/SSE: Real-time updates
Events: message, typing, error, connected
Error Handling
Network errors: User-friendly messages, retry logic
API errors: Handle 4xx/5xx appropriately
Timeout handling: Show timeout, allow retry



Rate limiting: Show message, disable input temporarily

Rate Limiting: Implement client-side rate limiting to prevent abuse
Offline Support: Consider service worker for offline message queuing
